赋值、字符串运算和算术运算可以直接在配置文件中完成。

## 赋值

赋值可以像 C 语言那样使用 `=`（等号）运算符完成。注意并非所有脚本变量都可写，有些是只读的。查看[变量列表](Script-CoreVar.md)以了解哪些变量可写。

```opensips

$var(a) = 123;
$ru = "sip:user@domain";

```

有一个特殊的赋值运算符 `:=`（冒号等号），可用于 AVP。如果右侧值为**空值**，则删除该名称的所有 AVP。否则，新值会覆盖该名称 AVP 的所有现有值（换言之，它删除同名的现有 AVP，并添加一个值为右侧值的 AVP）。

```opensips

$avp(val) := 123;

```

## 字符串运算

对于字符串，可以使用 '+' 进行拼接。

```opensips

$var(a) = "test";
$var(b) = "sip:" + $var(a) + "@" + $fd;

```

## 算术与位运算

对于数字，可以使用：

* + ：加
* - ：减
* / ：除
* * ：乘
* % ：取模
* | ：按位或
* & ：按位与
* ^ ：按位异或
* ~ ：按位取反
* \<< ：按位左移
* \>> ：按位右移

示例：

```opensips

$var(a) = 4 + ( 7 & ( ~2 ) );

```

> [!NOTE]
> 为确保表达式中操作数的优先级，请使用__括号__。

算术表达式可以通过测试运算符 ' [ ... ] ' 用在条件表达式中。

```opensips

if( [ $var(a) & 4 ] )
    log("var a has third bit set\n");

```
