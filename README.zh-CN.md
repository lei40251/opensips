# 欢迎来到 OpenSIPS 项目

## 项目简介

OpenSIPS 是一个采用 GPL 许可证的 SIP 服务器实现，最初派生自 Fokus Fraunhofer 的 SIP Express Router（SER）项目。OpenSIPS 致力于成为一个更开放的项目——不只是在许可证层面，更体现在项目管理方式上，尤其是对外部贡献的接纳。

OpenSIPS 希望解决 SER 项目开发迭代迟缓的问题，让新增功能能够更快地进入正式发布。项目由 OpenSIPS Solutions（<http://www.opensips-solutions.com/>）维护，团队中包含 SER 项目的核心开发者与主要开发者。

## 问题与交流

* OpenSIPS 使用相关的问题，请发到公开邮件列表 <users@lists.opensips.org>。
* 开发相关的问题（代码贡献、缺陷报告等），请发到公开邮件列表 <devel@lists.opensips.org>。
* 商务相关的问题（产品、咨询、培训等），请发到公开邮件列表 <business@lists.opensips.org>。
* 此外还有一个综合资讯邮件列表 <news@lists.opensips.org>，用于了解项目的最新动态、重要事项、版本发布与安全公告，以及项目周边活动。
